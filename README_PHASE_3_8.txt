GAME MASTER'S KEEP — PHASE 3.8
Character Sheet Intelligence

Built from the approved Phase 3.7 character-sheet foundation.

New automatic calculations for The Chronicles of Puma (D&D 5E 2014):
- Proficiency bonus is calculated from character level (levels 1–20).
- Spell save DC and spell attack bonus are calculated when a spellcasting ability is selected.
- Passive Perception is calculated from Wisdom and the Perception proficiency listed in the skill proficiencies field.
- Character Quick View displays the derived spell statistics.

Important:
- Saving throw and skill proficiency fields remain descriptive text; this build does not yet calculate every individual skill/save row.
- Weapon attacks, armor, spell slots, HP changes, and resource counters are not yet live-linked to the Rules Library.
- Verify character values against the 2014 rules and your table's rulings.

LOCAL TESTING:
1. Extract the ZIP into a NEW folder.
2. Open game_masters_keep_v1/index.html.
3. Select The Chronicles of Puma and create/edit a character.
4. Change level from 1 to 5, 9, 13, and 17; proficiency should update to +3, +4, +5, and +6 respectively.
5. Choose Intelligence, Wisdom, or Charisma as spellcasting ability and change its score; confirm save DC and attack bonus update.
6. Add Perception to the skill proficiencies text; confirm passive Perception includes proficiency.
7. Save, reopen the character sheet, and verify values persist.
8. Confirm Starfleet Command and Galactic Adventures still behave as before.

Phase 2 and GitHub are not modified by this prototype.
