GAME MASTER'S KEEP — PHASE 3.11

To test:
1. Extract the ZIP file.
2. Open game_masters_keep_v1/index.html in a modern desktop browser.
3. Select The Chronicles of Puma.
4. Open Dungeon Master's Toolkit from the left navigation.
5. Try the Adventure Seed, NPC, and Forgotten Place generators.
6. Try the encounter calculator with a party such as 3, 3, 3, 3 and two CR 1 monsters.
7. Save results and confirm they appear in Saved Toolkit Results.

This is a local prototype. Data remains in the browser where it was entered. Keep your Phase 3.10 ZIP as a rollback copy. No GitHub deployment is performed by this build.
