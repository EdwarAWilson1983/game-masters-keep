PHASE 3.12 — CHARACTER SHEET COMPLETION

1. Extract this ZIP.
2. Open game_masters_keep_v1/index.html in your browser.
3. Select The Chronicles of Puma and open a campaign.
4. Go to Characters & NPCs, create or edit a character, and complete the 5E Character Sheet section.
5. Save, then choose View character sheet on the character card.
6. Test the live HP, temporary HP, death-save, hit-dice, and inspiration controls.

Keep your Phase 3.11 ZIP as a rollback copy until you have tested this version. Campaign data remains in the browser's local storage; export a JSON backup before major changes.
