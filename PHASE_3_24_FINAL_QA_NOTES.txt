GITHUB PAGES DEPLOYMENT NOTES
- GitHub Pages is static hosting. This build remains a local, single-browser application; campaign data is stored in browser storage and is not automatically synchronized between devices or users.
- Do not upload private campaign notes, sensitive personal data, or copyrighted source PDFs into a public repository.
- Before deployment, confirm the repository's Pages source/branch and the expected project path. The app's configured base URL should be checked against the actual repository URL.
- Preserve a complete copy of the currently working repository before replacing files.
- Upload the contents of the game_masters_keep_v1 folder to the intended repository root (not the containing ZIP folder).
- After deployment, test the live URL in a fresh browser session and verify asset paths, navigation, storage, and JSON backup export/import.

COST / ARCHITECTURE
No server, paid API, subscription, or backend dependency was added. GitHub Pages does not itself provide accounts, private shared campaigns, or multiplayer synchronization. Those remain Phase 4 architecture decisions and must be evaluated against the strict $0/month requirement.
