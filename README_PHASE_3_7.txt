PHASE 3.7 — CHARACTER SHEET FOUNDATION

Open index.html in a browser. In The Chronicles of Puma, open Characters & NPCs, create or edit a character, and use the 5E Character Sheet section to enter play statistics. Save the character, then choose View Character Sheet on its card.

This is a local prototype. Character information is saved in the current browser only. Export a JSON backup regularly. Starfleet Command and Galactic Adventures retain their existing character dossier workflow; this build does not apply D&D 5E fields to those universes.
